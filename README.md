# ZeroHush

> A lightweight, memory-efficient pixel art and drawing tool for Windows.

ZeroHush is an extremely lightweight pixel art and drawing tool for Windows. It launches blazing fast, consumes minimal memory, and is completely open-source and free.

## ✨ Features

- **Extremely Lightweight**: The installer is only ~60MB (including the .NET runtime), and it launches in just 1 second.
- **Low Memory Footprint**: Utilizes lazy allocation technology, idling at only ~48MB of RAM.
- **Complete Drawing Experience**: Supports Pen, Eraser, Bucket Fill, Line, Rectangle, Ellipse, Multi-layer support, Layer folders, and Undo/Redo history.
- **Highly Customizable**:
  - 🎨 Multiple built-in themes + custom color palettes
  - 🌍 Multi-language support (Built-in EN/CN, supports external language packs)
  - 🔌 Plugin system (Supports external DLL extensions)
- **Open Source & Free**: Licensed under MIT, with fully public source code.

## 🚀 Download & Installation

Go to the [Releases](https://github.com/xnyxyzaf/ZeroHush/releases) page to download the latest `ZeroHush-v1.0.0-beta-win-x64.zip`.

1. Unzip the file to any folder.
2. Double-click `ZeroHush.exe` to run. No installation required.

*System Requirements: Windows 10 version 1809 or higher (64-bit).*

## 🛠️ Tech Stack

- C# / .NET 10
- WPF (Windows Presentation Foundation)
