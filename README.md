## ✨ 功能特性

- **🪶 极致轻量**：安装包仅 ~60MB（含 .NET 运行环境），启动仅需 1 秒。
- **💾 低内存占用**：采用延迟分配技术，空闲状态仅占用 ~48MB 内存。
- **🖌️ 完整的绘画体验**：支持画笔、橡皮擦、油漆桶、吸管、直线、矩形、椭圆。
- **📚 多图层支持**：支持图层、图层文件夹以及完整的撤销/重做历史记录。
- **🎨 高度可定制**：
  - 🌓 多种内置主题 + 自定义调色板
  - 🌍 多语言支持（内置中/英双语，支持外部语言包）
  - 🔌 插件系统（支持外部 DLL 扩展）

## 📥 下载与安装

请前往 [Releases](https://github.com/xnyxyzaf/ZeroHush/releases) 页面下载最新的 `ZeroHush-v1.0.0-beta-win-x64.zip`。

- **免安装**：解压到任意文件夹。
- **一键启动**：双击 `ZeroHush.exe` 即可运行。

> **系统要求**：Windows 10 (1809) 或更高版本 (64位)。

## 💻 技术栈

- **UI 框架**：WPF (Windows Presentation Foundation)
